# Glossary of Terms

## CMS Terms
* **CMS:** Content Management System - this is the primary means of creating and editing content.
* **Content Editor:** Any user that has permission to create, edit, or delete content in the CMS.
* **Administrator:** The administrative user(s) that have permission to carry out any CMS request. This involves activities that require more scrutiny and oversight such as creating and managing user accounts, setting up site-wide permissions, etc. 
* **Backoffice:** The area of CMS that content editors log into to manage content.
* **Page:** Any page of content that is created and managed in the CMS.
* **Block:** Reusable "modules" that provide custom functionality or formatting for a specific component on a page, ex: CTA List Block.
* **Element:** A block that is used within the flexible content area.
* **Node:** An item that exists in the tree.
* **Tree:** A tree is a hierarchical list of items related (and usually restricted) to a specific concept.

## Website Terms

* **Header:** The very top portion of the page that provides navigation for the site.
* **Footer:** The very bottom portion of the page that provides site-wide links, social media information, and copyright text. 
* **Hero:** Describes the top portion of the page below the global header that can be used to display a banner image.
* **Teaser:** Brief information about a page that entices users to view the full content. 
* **Call to Action (CTA):** A section that asks a user to perform a task by giving them an action link (ex. Register, Buy Now, etc.). 
* **SEO (Search Engine Optimization):** Certain tasks or fields you can fill out to increase your content's rankings in external search engines, such as Google.
